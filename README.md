# 拾知

运营岗位资质刷题网站。日系留白界面，适配电脑、安卓手机和 iPhone 的现代浏览器。纯 HTML / CSS / JavaScript，无需购买服务器，无需安装 Node.js，也没有外部字体、图片或运行时 CDN 依赖。

## 先部署，再开始刷题

交付 ZIP 的根目录已经是可直接发布的网站。**解压后上传里面的文件，不要只把 ZIP 上传到 GitHub。**

1. 登录 GitHub，新建一个仓库，例如 `shizhi`。
2. 在仓库中选择 **Add file → Upload files**，上传解压得到的文件与文件夹。确认 `index.html` 位于仓库根目录，而不是多嵌套一层文件夹。
3. 提交上传。进入仓库 **Settings → Pages**。
4. 在 **Build and deployment → Source** 选择 **Deploy from a branch**。
5. 分支选 `main`，文件夹选 **/ (root)**，点击 **Save**。
6. 等待 GitHub 完成发布。Pages 页面会显示网址，通常为 `https://你的用户名.github.io/shizhi/`。用电脑或手机打开即可。

部署方式依据 [GitHub Pages 官方说明](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)。本包不需要 GitHub Actions 自定义工作流，不需要构建命令。题库直接包含在前端文件中，公开发布后访问者可以读取；请自行确认单位题库允许公开发布。私有仓库本身不等于网站私密。

## 在电脑和手机上使用

- **Windows**：Edge / Chrome / Firefox 等现代浏览器打开网址；支持安装的浏览器可通过菜单安装。
- **安卓**：Chrome 等浏览器打开网址，可使用菜单里的“安装应用”或“添加到主屏幕”。
- **iPhone**：Safari 打开网址 → 分享 → 添加到主屏幕。
- 首次联网访问并完成资源缓存后，可以离线使用。系统或浏览器清理缓存后，需要重新联网准备资源。
- 安装支持受浏览器影响；普通网页刷题无需安装。PWA 安装能力参考 [MDN 官方文档](https://developer.mozilla.org/en-US/docs/Web/Progressive_web_apps/Guides/Making_PWAs_installable)。

也可以在电脑上双击 `index.html` 快速查看和刷题；正式使用建议部署到 HTTPS 网站。`file://` 方式不提供 Service Worker 离线安装，浏览器对本地文件的存档行为也可能不同。安装了 Python 的电脑可在网站根目录运行 `python -m http.server 8000`，再打开 `http://localhost:8000/`。

## 题号、判分与统计说明

- 题库共 **2,957 题**：单选 1,119、判断 975、多选 863。
- 8 个分类：必考题 48，审计部 146，财务会计部 185，运营管理部 1,352，普惠金融部 765，金融市场部 95，风险管理部 112，办公室 254。
- 原表各部门题号重新从 1 开始，因此“1–50”指**所选部门内原题号**。如果选择全部部门，这个范围会分别应用于所有部门。
- 答题卡上的数字指本轮题序；题目上方另显示部门和原题号。
- 多选题必须与标准答案完全一致，多选、漏选都算错。考试每题等分，百分制；未答题交卷后计错。
- 正确率 = 累计答对次数 ÷（累计答对次数 + 累计答错次数）。重复作答与闪卡自评都计入，背题浏览不计入。
- 同一轮已经确认的题不能反复提交刷次数。循环到期或主动提前加练时开启新一次作答。
- “错题”是曾经答错的历史集合，不会因一次答对而清除；“已掌握”独立表示完成记忆计划。
- 原题库没有解析。本网站提供原标准答案和个人笔记，不编造解析，未核验业务制度或法规的现行有效性。

## 循环与记忆计划

推荐：开始练习 → 循环掌握 → 选“运营管理部” → 起始 1、结束 50、题量 50。想只练 1–30 则把结束题号和题量都改为 30。

1. 初次答错：1 分钟后安排重试，记忆阶段归零。
2. 第 1 次符合时间条件的答对：进入阶段 1，10 分钟后复习。
3. 随后按时答对，依次安排 1 天、3 天、7 天、14 天、30 天后复习。
4. 第 7 阶段答对后标记为“已掌握”，自动移出循环调度。
5. 任何一次答错都会回到起点，1 分钟后再试，包括此前已掌握的题。
6. 尚未到期时，页面会显示等待；可以离开，也可以选择“提前加练”。提前答对增加次数，但不推进记忆阶段。

这意味着完整掌握需要跨天复习，不会在一次连续点击中完成。此算法是基于递增间隔的实用安排，并非对个人遗忘概率的精确预测。所有模式共享同一道题的记忆进度。循环计划在“记忆计划”页面保留，可删除计划而不删除题目学习历史。

## 26 套皮肤

纸间、墨色书房、宝可梦灵感点阵绿、GBA 紫晶掌机、赛博朋克霓虹雨、星露谷灵感麦田、新海诚灵感晴空、樱雨、抹茶、海盐、雪国、落日、蓝图、终端、咖啡、薰衣草、月面、深海、橘白、薄荷、酒红、沙丘、钴蓝、电子墨水、街机像素夜、森林苔石。

点阵／像素主题使用方角和硬边框，网格主题使用低对比网格，霓虹主题仅在界面边缘发光，晴空主题使用轻渐变。皮肤不含原作品角色、美术或音乐。阅读区不使用闪烁效果。配色会自动进行基础对比度修正；页面亮度滑块不改变硬件屏幕亮度。

## 学习记录与换设备

这是适合 GitHub Pages 的纯静态个人学习工具，**没有账号系统，也没有自动云同步**。记录保存在当前浏览器的 `localStorage` 中，存储键为 `shizhi.v1`。

换设备时：旧设备“偏好设置 → 导出进度”，把 JSON 传给新设备，在同一版本拾知中导入。导入将覆盖当前设备存档，先导出可保留两份。请避免同时在多个标签页独立刷题，以免互相覆盖记录。浏览器无痕模式、清理网站数据、换浏览器或换域名都可能导致记录不可用。

## 文件说明与后续修改

| 文件 | 用途 |
|---|---|
| `index.html` | 网站入口 |
| `styles.css` | 响应式界面、主题质感 |
| `app.js` | 页面、刷题、统计、存档逻辑 |
| `engine.js` | 判分、记忆调度、选题算法 |
| `questions.js` | 从原表转换的完整题库 |
| `themes.js` | 26 套主题配置 |
| `sw.js` | 离线缓存 |
| `manifest.webmanifest`、`icon*` | 桌面安装与图标 |
| `import-report.json` | 题库数量、分布和结构校验报告 |
| `tools/import_xlsx.py` | Excel 转换脚本，仅用 Python 标准库 |
| `tests/engine.test.cjs` | 判分与调度核心测试 |

更新题库：保留原表第一张工作表的 11 列结构（序号、部门、题型、题目、答案、选项 A–F），运行：

```bash
python tools/import_xlsx.py 新题库.xlsx .
```

检查生成的 `import-report.json`。题目 ID 来自“部门＋序号＋题干”的稳定摘要；这些字段不变时历史进度会保留，改动后视为新题。更新题库后建议先备份旧进度。

**每次修改网站后**，把 `sw.js` 中的 `VERSION` 改为新版本，例如 `shizhi-v1.0.1`，再上传全部改动。首次重新联网打开后，关闭并重新打开网页，使新缓存生效。若仍显示旧版，可清除缓存后重开；清除“网站数据”可能同时清除学习进度，应先导出。

运行核心测试（可选，需要 Node.js）：

```bash
node tests/engine.test.cjs
node tests/app.test.cjs
```
